    13→- Built the rules data (`src/lib/rules-data.ts`) — 12 UK Skilled Worker visa rules across 5 categories (core, job, funds, language, character).     14→- Built the rules engine (`src/lib/rules-engine.ts`) — pure in-memory evaluator. The gate runs at the engine layer: if the rule's serialized JSON contains `PENDING_HUMAN_CLICK`, `displayedVerdict` is forced to `"pending"` regardless of what the logical `evaluate()` returned. The `logicalVerdict` is preserved for transparency.
    15→- Built the API route (`src/app/api/check/route.ts`) — `POST /api/check`, runtime `nodejs`, dynamic. Reads answers + lang from the request body, evaluates in-memory, returns the result with strict no-store cache headers. No logging of answers, no disk writes, no KV.
